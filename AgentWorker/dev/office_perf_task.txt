PERFORMANCE TASK for the game in tamagotchi/ (only that folder is the live game). The game renders only about 84 frames
per second headless, which makes the acceptance checker take 7 minutes. A profile of 300 frames shows the cause:
4.9 million calls to pygame.draw.rect (about 16,000 per frame: the floor, walls and furniture are redrawn rectangle by
rectangle EVERY frame), and a font file opened for every text render (draw_utils.dt creates a new pygame.font.Font on
each call).

Make it fast WITHOUT changing what is drawn:
 - Draw everything that never changes (floor tiles, walls, static furniture) ONCE at startup onto a cached
   pygame.Surface of the whole 800x520 world, and blit the visible part of that surface each frame.
 - Create each pygame.font.Font once (cache by size) instead of on every call.
 - Keep one full repaint and exactly one display flip per frame; keep the --script and live paths identical.
 - The picture must stay pixel-identical, also when the camera has moved: the VERIFY commands below compare
   `--frames 30` with the protected ref_shot.png and `--script right:40,down:30 --frames 90` with ref_shot_walk.png.
Goal: `python3 perf_check.py` passes (600 frames in at most 2.5 s). Run it, and the image comparison, after each change.
